# crop-weed-prediction-project
The weeds in the agriculture field are predicted in this project using ML 
An intelligent computer vision system designed to detect and differentiate sesame crops from unwanted weeds in real-time. By identifying weed coordinates with bounding-box precision, this system lays the technical foundation for automated, targeted pesticide sprayers—reducing chemical waste and preventing crop contamination

Project Overview

Unwanted weeds consume crucial nutrients, water, and land resources that belong to crops, leading to significantly lower agricultural yields. Standard manual or blanket spraying methods apply harmful pesticides to crops and surrounding soil, increasing costs and posing potential health risks.

This project solves this challenge by leveraging deep learning object detection algorithms  to pinpoint weeds for localized, precision pesticide application.
